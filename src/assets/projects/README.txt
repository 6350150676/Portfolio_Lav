PROJECT IMAGES — drop your pictures here
========================================
Each project has its OWN folder below. Put as many (or as few) images as
you want into a project's folder — the site shows exactly what's there.

  src/assets/projects/checkers-multiplayer/
  src/assets/projects/zip-puzzle/
  src/assets/projects/vr-acrophobia/
  src/assets/projects/car-racing/
  src/assets/projects/fpv-drone/

RULES
-----
• Thumbnail/cover: name ONE file  cover.jpg  (or cover.png / cover.webp).
  If you don't add a cover.*, the first image is used as the cover.
• Every other image shows in the project's "Screens" gallery (click to zoom),
  in filename order — so prefix them 01-, 02-, 03- to control the order.
• The filename becomes the caption:
      01-in-game-hud.jpg  →  "In-game hud"
• No images in a folder  →  that project shows no cover photo and no gallery.
• Any number is fine (1, 3, 10…). Keep each under ~400 KB; .jpg/.webp best.
• Recommended sizes: cover ~1200×750 (16:10), gallery ~1280×720 (16:9).

That's it — save a file into the folder and it appears automatically.
